## About

**Gunshell Reloaded** is an unofficial modified version of the original Gunshell Minecraft plugin.

This version has been updated and reuploaded to keep the plugin usable and accessible for server owners who still want to use Gunshell.

This project is based on the original Gunshell source code and remains free and open-source under the AGPL-3.0 license.

## Resource Packs

Original resource packs may still be required depending on the version you are running:

- **1.12.2:** https://dash.gunshell.nl/downloads/Gunshell-v1.12.2.zip
- **1.16+:** https://dash.gunshell.nl/downloads/Gunshell-v1.16+.zip

## Optional Dependencies

### CombatTagPlus

Gunshell Reloaded can optionally hook into CombatTagPlus.

The CombatTagPlus plugin file is not included in this repository. Download and install CombatTagPlus separately on your server if you want this hook enabled.
