## About

**Gunshell Reloaded** is a reloaded version of the original Gunshell Minecraft plugin.

This version has been modified, updated, and reuploaded while remaining free and open-source in respect of the original GPL license. The goal of this reloaded version is to keep the plugin usable, maintained, and accessible for server owners who still want to use Gunshell.

This project is based on the original Gunshell plugin.

# CombatTagPlus Dependency

Gunshell Reloaded can optionally hook into CombatTagPlus.

The CombatTagPlus plugin file is not included in this repository.
Download/install CombatTagPlus separately and place it on your server if you want this hook enabled.

This folder exists only to document the optional dependency.
